## Evidence boundaries

Only Power Shots currently has twelve situations and eight intended rank profiles.
Workshop launch and arbitrary plugin activation remain gated. The reviewed rank,
settings and lifecycle-observer changes are isolated source candidates. Existing
test counts overlap; do not add them into a claimed unique total. Source snapshots
can differ from the repository's current main branch; reconcile files before use.

Raw captures, saves, credentials, private paths, decompiled proprietary code and
extracted game assets stay outside this folder and outside GitHub. Public API
declarations and native names do not establish actual call order or grant ownership
of cosmetics. Garage research will distinguish catalog/preview support from
account-owned items and online visibility.
