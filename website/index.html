The October 24 Windows ZIP has a confirmed startup crash. A replacement download will be listed after testing.

What happened: Live Windows tests reproduced a crash while Rocket League loads the replacement menu. Passing code checks did not prove that the game worked. The old ZIP is not a working release.

Simpler installation: The replacement is being prepared as one Windows setup file and one My Career Training shortcut. The Worker is an internal helper; players should never need to open it.

What you need: Your installed Steam copy of Rocket League and BakkesMod. BakkesMod hosts the in-game controls; RLBot runs the offline bots. Python, Visual Studio and Cursor are build tools, not player requirements. The current test targets Steam build ID 25914621; other builds are refused.

Planned menu: My Career, Training, Garage, Workshop, Community and Settings. The custom buttons, gameplay and return to normal Rocket League must pass live testing before this is described as working.

Current limits: Car bodies use your owned Garage choices. Imported local maps are not launchable yet. Community plugins can be downloaded and cached; only the reviewed Speedflip Trainer has a trial activation route.

Offline sessions: Rocket League's official offline launch mode disables Easy Anti-Cheat for that session. Its notice offers instructions for enabling it: choose No to dismiss those instructions and remain offline. Normal account and cloud connections are not blocked.
