A solo Rocket League career played through a personalized menu in offline mode.

Windows build: Version 0.3.0 is in development. The native-menu download is not ready yet.

Current work: A native dialog trial for Career and Training is in the source. It still needs testing inside the Windows game and does not replace the full menu yet.

Still to verify: Native menu buttons must work in the current Steam build, route to career actions, and restore the original menus safely.
