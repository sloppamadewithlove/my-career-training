## Design only

Claude Opus 5.5 high provides visual mockups/specifications and design reviews.
Builders author all implementation, including HTML/CSS/JavaScript previews, input
behavior and compilation. Use existing authorized login; verify actual model.
If unavailable, report it and keep the assignment pending, not silently substituted.
The owner allowed DeepSeek design help for this revision only; that is not a permanent
Opus implementation role. Designers inspect reference/evidence, never operate the game.

## Current assignments

1. Garage: category/slot tabs, full supported installed-catalog thumbnail grid,
   search/filter, paint compatibility, live preview and compact item details.
   Preserve normal preset and make unsupported items clear; no online unlock promises.
2. Training browser: blue/navy panel, scrollable rows and selected-item detail panel;
   Lessons/Workshop/Mods/Favorites, consistent real thumbnails in every tab, creator
   and update date where known, search/filter and one clear primary action.
   Show loading/missing-image/unavailable states. No More/Previous button maze.
3. Controller: transparent DualShock 4 silhouette, responsive verified inputs, no
   rectangular card or persistent technical labels. On/Off only; avoid stock boost HUD.
   Distinguish player and ghost controllers. Evaluate compatible existing helpers
   before duplicating them, without assuming redistribution rights.
4. Lesson HUD: readable scenario index 1–12, setup/goal, useful feedback, retry and ghost
   state. Adjustable training defaults Left previous/Right next/Up ghost/Down retry.
   Direct entry with in-session options and one Return home; no preflight action pages.
5. Ghost: readable oriented car, visible front/roof/underside, non-contact demo and
   synchronized controller; shots/flip resets use a fixed-start ghost and its own
   faint non-contact demonstration ball, distinct from the playable ball. A design or
   mock motion is not a valid skill recording.
